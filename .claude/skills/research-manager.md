Запускаю исследовательский пайплайн по теме: **$TOPIC**

---

Я — оркестратор. Провожу исследование в 5 шагов последовательно. После каждого шага сообщаю о прогрессе.

## Подготовка

Сначала создам рабочую директорию для этой сессии:

```bash
SESSION_ID=$(date +%Y%m%d_%H%M%S)
SESSION_DIR="Исследователь/artifacts/$SESSION_ID"
mkdir -p "$SESSION_DIR/findings"
echo "Сессия: $SESSION_DIR"
```

Запомни `SESSION_DIR` — все файлы пойдут туда.

---

## ШАГ 1 — Декомпозиция темы на аспекты

**Цель:** разбить тему на 7–8 аспектов через разные призмы (who, what, why, so what, how, when, avoid, counter).

Использую skill `research-decomposer` с темой `$TOPIC`.

После получения списка аспектов — разберу его и создам план:

```bash
cat > "$SESSION_DIR/plan.yaml" << 'YAML'
topic: "$TOPIC"
session_id: "$SESSION_ID"
created_at: "$(date -u +%Y-%m-%dT%H:%M:%SZ)"
aspects:
  - id: a01
    name: "..."
    description: "..."
    queries:
      - "..."
      - "..."
      - "..."
  - id: a02
    ...
YAML
```

Сообщу: `✓ Шаг 1 завершён. Аспектов: N`

---

## ШАГ 2 — Параллельный рисёрч аспектов

**Цель:** для каждого аспекта запустить субагента `aspect-researcher`, который ищет через Exa API и сохраняет находки.

> Внимание: перед запуском проверь наличие переменной `EXA_API_KEY`:
> ```bash
> echo "EXA_API_KEY установлен: ${EXA_API_KEY:+да}"
> ```
> Если не установлен — сообщи пользователю и останови.

Для каждого аспекта из плана запускаю субагента через Task tool:

**Промпт для каждого субагента:**
```
Исследуй аспект темы "[TOPIC]".

aspect_id: [ID]
aspect_name: [NAME]
aspect_description: [DESCRIPTION]
queries:
  - [QUERY_1]
  - [QUERY_2]
  - [QUERY_3]
output_path: [SESSION_DIR]/findings/[ID].yaml

Следуй инструкциям агента aspect-researcher.
```

Запускаю аспекты **последовательно**, один за другим. После каждого:
- Проверяю что файл `findings/[ID].yaml` создан
- Сообщаю: `  ✓ Аспект [N/TOTAL]: [name]`

Если файл не создан — повторяю запрос один раз с пометкой "повторная попытка".

После всех аспектов:
`✓ Шаг 2 завершён. Находок: [суммарно]`

---

## ШАГ 3 — Синтез находок

**Цель:** объединить все аспекты в единую картину, найти сквозные паттерны и неожиданные связи.

Использую skill `research-synthesizer` с параметрами:
- `TOPIC` = $TOPIC
- `FINDINGS_DIR` = `$SESSION_DIR/findings`
- `OUTPUT_PATH` = `$SESSION_DIR/synthesis.yaml`

Прочитаю все файлы из `findings/`, применю логику синтезатора, запишу результат.

`✓ Шаг 3 завершён. Ключевых инсайтов: N`

---

## ШАГ 4 — Red Team: проверка предположений

**Цель:** атаковать синтез как скептик — найти bias, слабые места, альтернативные объяснения.

Запускаю субагента `red-team` через Task tool:

**Промпт:**
```
Проведи red team атаку на результаты исследования.

topic: $TOPIC
synthesis_path: $SESSION_DIR/synthesis.yaml
output_path: $SESSION_DIR/red-team.yaml

Следуй инструкциям агента red-team.
```

После завершения:
`✓ Шаг 4 завершён. Критических проблем: N, уверенность: [strength]`

---

## ШАГ 5 — Финальный отчёт

**Цель:** упаковать всё в читаемый Markdown-отчёт.

Запускаю субагента `report-generator` через Task tool:

**Промпт:**
```
Сгенерируй финальный исследовательский отчёт.

topic: $TOPIC
plan_path: $SESSION_DIR/plan.yaml
findings_dir: $SESSION_DIR/findings
synthesis_path: $SESSION_DIR/synthesis.yaml
red_team_path: $SESSION_DIR/red-team.yaml
output_path: $SESSION_DIR/report.md

Следуй инструкциям агента report-generator.
```

После завершения прочитай отчёт и выведи его пользователю в чат полностью.

`✓ Шаг 5 завершён. Отчёт сохранён: $SESSION_DIR/report.md`

## Обработка ошибок

- **EXA_API_KEY не установлен** → остановись, попроси пользователя: `export EXA_API_KEY=your_key`
- **Субагент не создал файл** → одна повторная попытка, затем пропусти аспект и продолжи
- **Менее 3 аспектов с данными** → остановись до синтеза, сообщи о проблеме
- **Синтез пустой** → не запускай red team и report, сообщи об ошибке
