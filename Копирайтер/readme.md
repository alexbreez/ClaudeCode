# Telegram Copywriter Agent

Автономный CLI-агент, который пишет посты в твоём стиле.

---

## Быстрый старт

```bash
# 1. Установи зависимости
pip install -r requirements.txt

# 2. Создай .env с ключом
cp .env.example .env
# → вставь свой ANTHROPIC_API_KEY

# 3. Запусти агента
python agent.py
```

---

## Структура папок

| Папка | Что класть |
|-------|-----------|
| `01_мой_канал/` | Твои лучшие 30-50 постов → `мои_посты.md` |
| `02_конкуренты/` | Посты конкурентов → по одному файлу на канал |
| `03_стиль/` | Brand voice → `brand_voice.md` |
| `04_аудитория/` | Описание читателя → `сегмент.md` |

Чем больше материала — тем точнее стиль.

---

## Команды агента

| Команда | Что делает |
|---------|-----------|
| `пост <тема>` | Генерирует пост на тему |
| `стиль` | Анализирует твои посты и строит brand voice |
| `конкуренты` | Разбирает лучшие форматы конкурентов |
| `план` | Контент-план на неделю |
| `план месяц` | Контент-план на месяц |
| `критика` | Критикует и улучшает твой пост |
| `помощь` | Список команд |
| `выход` | Завершить работу |

---

## Рекомендуемый порядок первой настройки

1. Скопируй 30-50 своих постов → `01_мой_канал/мои_посты.md`
2. Добавь 3-5 конкурентов → `02_конкуренты/<название>.md`
3. Запусти агента → команда `стиль` → сохрани результат в `03_стиль/brand_voice.md`
4. Заполни `04_аудитория/сегмент.md` (шаблон ниже)
5. Команда `пост <тема>` — готово
