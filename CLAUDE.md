# Telegram Copywriter Agent — Claude Code

Ты — интерфейс для агента-копирайтера Telegram-канала.
Все команды выполняй через `python Копирайтер/agent.py <команда>` и возвращай результат пользователю.

---

## Доступные команды

| Что пишет пользователь | Что запускать |
|------------------------|---------------|
| `пост <тема>` | `python Копирайтер/agent.py пост "<тема>"` |
| `стиль` | `python Копирайтер/agent.py стиль` |
| `конкуренты` | `python Копирайтер/agent.py конкуренты` |
| `план` | `python Копирайтер/agent.py план` |
| `план месяц` | `python Копирайтер/agent.py план месяц` |
| `критика <текст>` | `python Копирайтер/agent.py критика "<текст>"` |
| `помощь` | `python Копирайтер/agent.py помощь` |
| `исследование <тема>` | Запустить 5-шаговый research pipeline (см. ниже) |

---

## Правила работы

1. **Запускай команды сразу** без лишних вопросов.
2. Рабочая директория: `/home/user/ClaudeCode`
3. Если пользователь пишет тему поста без команды — уточни: написать пост или добавить в план?
4. После команды `стиль` — предложи сохранить результат в `03_стиль/brand_voice.md`.
5. Если нет постов в `01_мой_канал/мои_посты.md` — попроси пользователя добавить их перед анализом.

## Агент-исследователь (Research Pipeline)

Когда пользователь пишет `исследование <тема>` — запусти skill `research-manager` с темой в качестве `$TOPIC`.

### Что происходит внутри (5 шагов):
1. **Декомпозиция** — тема разбивается на 7–8 аспектов через призмы (who/what/why/so what/avoid/counter)
2. **Рисёрч** — субагент `aspect-researcher` исследует каждый аспект через Exa API
3. **Синтез** — находки объединяются, ищутся паттерны и связи между аспектами
4. **Red Team** — субагент `red-team` атакует синтез: ищет bias, дыры, альтернативные объяснения
5. **Отчёт** — субагент `report-generator` создаёт финальный Markdown-документ

### Где результаты:
`Исследователь/artifacts/<session_id>/report.md`

### Требования:
- Переменная `EXA_API_KEY` должна быть установлена в окружении
- Если не установлена — скажи пользователю: `export EXA_API_KEY=your_key_here`

## Как добавить посты

Пользователь может:
- Вставить тексты постов прямо в чат → ты записываешь их в `Копирайтер/01_мой_канал/мои_посты.md`
- Передать HTML-файл из Telegram Desktop → ты парсишь и записываешь

Формат записи:
```
## Пост N

<текст поста>

---
```
